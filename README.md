# NUMERIA · Screening de competencia numérica

Prototipo de **Colmenia**.

👉 **[Abrir el screening](https://foniafonia.github.io/numeria-prototipo/)**

## Qué es

Una sesión breve (10-15 minutos) de tareas numéricas que devuelve un perfil por
dominios y un informe comprensible para la familia y para profesionales.

Evalúa seis dominios: sentido de cantidad (subitización), comparación de
cantidades, comparación de números, recta numérica, cálculo básico y fluidez
aritmética.

## Qué NO es

**No es una prueba diagnóstica.** No dice si un niño o una niña tiene
discalculia, ni lo descarta. No da porcentajes ni probabilidades diagnósticas.
No usa baremos, porque todavía no existen datos normativos para esta
herramienta. No sustituye la evaluación de un profesional cualificado.

Su función es la de un cribado: señalar patrones de desempeño que puedan
justificar una valoración profesional posterior.

## Cómo funciona esta versión

Todo se ejecuta dentro del navegador. No hay servidor, no se guarda nada y no se
envía ningún dato a ningún sitio. Al cerrar la página los resultados se pierden,
así que conviene guardarlos en PDF desde la propia pantalla de resultados.

Las puntuaciones las calcula un motor de reglas determinista: la misma sesión
produce siempre las mismas métricas. Los informes de esta versión los redacta
también un motor de reglas, no un modelo de lenguaje.
